BSA STUDY DESK v146 — MAIN + SHARED

MAIN
1. Back up your current data before updating. Replace the main GitHub Pages files with the contents of the Main ZIP.
2. In the sidebar click Publish materials, or on mobile tap the Publish icon. This opens the existing Classmate sharing publisher.
3. Select subjects, supply a fine-grained GitHub token with Contents Read/Write access ONLY to your shared repository, and click Publish shared dashboard.
4. The token is not embedded in the student site. Publish again after adding or editing teaching materials. Publication is one-way and on demand, NOT live cloud syncing.

SHARED
1. The Shared ZIP contains starter materials. You only need to upload it for first setup. After that, publishing from the main v146 app writes the latest full shared index.html to the configured GitHub repository.
2. The shared app includes Study Path (Learn/Recall/Apply/Correct/Reflect), Lectures, Flashcards, Problem Sets, Practice, Mistake Log and Study Toolkit. Appearance is available. Owner grades, personal progress, Study Life, sharing and cloud sync stay private.
3. Learner progress is stored in localStorage for that particular origin/browser/profile. It does NOT roam between devices or sync to the owner. Publishing new content preserves existing learner progress for matching content IDs, local mistakes, local quiz scores, routine checks and appearance.
4. An owner deletion of teaching material removes that material from the published site; personal study records for removed subjects may not be visible. Export backups first.

IMPORTANT: If the shared site currently contains the newer published HTML, do not replace it with the starter ZIP! Instead update the MAIN app and press Publish. Back up and verify each deployment. iPad Home Screen PWA updates may be delayed by caching.

Verification: source JavaScript syntax and ZIP integrity checked. Full device Safari/PWA, real GitHub publish, and browser persistence were not verified.
